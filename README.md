# 🕹️ Jogo Detona Ralph

Projeto desenvolvido como desafio prático da **Digital Innovation One (DIO)**. O objetivo é testar os reflexos clicando no personagem Ralph conforme ele aparece nas janelas do prédio.

---

## 🎮 Como Funciona

- O jogo possui 9 janelas.
- O Ralph aparece aleatoriamente em uma das janelas.
- Cada clique correto no Ralph soma **1 ponto** ao placar (`Your Score`).
- O jogo possui contagem regressiva de tempo (`Time Left`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Flexbox / Grid, Fontes retrô)
- **JavaScript** (Lógica, temporizadores e manipuladores de eventos)
